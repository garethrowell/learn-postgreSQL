# learn-postgreSQL
Notes and code from 
Ferrari, L. and E. Pirozzi. 2023. Learn PostgreSQL. 2nd ed. Packt Publ. 1057 pp. 

I ran until this book a couple of years ago.
In the course of reading it, I decided to go all out and move my projects into PostgreSQL.
For me, the book was very motivational, definitely worth some time if you enjoy SQL and relational databases.
